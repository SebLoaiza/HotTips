HOT TIPS USER MANUAL

HotTips User Guide

Everything you need to install HotTips, import Toast reports, configure employees, distribute tips, and review payroll results.

Quick start: Download the latest release, import the three Toast CSV files using the same date range, complete Manual Inputs, review Tip Distribution, and confirm the Final Results.
01

Installing HotTips

Download the Installer

The HotTips installer is available through the official HotTips GitHub repository. Follow the instructions below to download and install the application.

1

Open the HotTips GitHub Page

  1. Open an internet browser on your computer.
  2. Click the address bar.
  3. Enter github.com/SebLoaiza/HotTips
  4. Press Enter.

The HotTips GitHub page contains the application files and latest software versions.

2

Find the Latest Release

  1. Locate the Releases section on the right side of the GitHub page.
  2. Click the latest available release.
HotTips v1.0.0
3

Download the Installer

  1. Scroll to Assets.
  2. Locate HotTips.Setup.1.0.0.exe.
  3. Click the installer and wait for the download to complete.
4

Run and Install

  1. Open your Downloads folder.
  2. Double-click HotTips Setup.exe.
  3. If Windows shows a security warning, select More Info, then Run Anyway.
  4. Wait while the application installs.
5

Open HotTips

Use the desktop shortcut or search for HotTips in the Windows Start Menu.

Troubleshooting: If the installer does not open, verify that the download completed, download it again, or restart the computer. If Windows blocks the installer, select More Info → Run Anyway.

03

Toast Inputs

The Toast Inputs page is where the required Toast data files are uploaded. HotTips requires three CSV files:

01 Shifts CSV
02 Orders CSV
03 Payments CSV
Important: All three files must use the same date range. Different date ranges may result in missing employees, incorrect sales, or inaccurate tip calculations.

Exporting CSV Files from Toast

Before downloading any files, set the desired date range, apply it, and use the same date range for all three reports.

Downloading the Orders CSV

  1. In Toast, select Reports → Sales → Orders.
  2. Select the date dropdown.
  3. Choose Custom Date.
  4. Enter the beginning and ending dates.
  5. Click Update.
  6. Export the report.
OrderDetails_YYYY_MM_DD-YYYY_MM_DD.csv

This file is the Orders CSV.

Downloading the Payments CSV

  1. Navigate to Reports → Payments → Payments .
  2. Confirm the date range matches the Orders report.
  3. Apply the report.
  4. Export the CSV file.
PaymentDetails_YYYY_MM_DD-YYYY_MM_DD.csv

This file is the Payments CSV.

Downloading the Shifts CSV

  1. Navigate to Reports → Labor → Time Entry Management .
  2. Confirm the date range matches the Orders and Payments reports.
  3. Apply the report.
  4. Export the CSV file.
Shifts_Closed_YYYY_MM_DD-YYYY_MM_DD.csv

This file is the Shifts CSV.

Uploading CSV Files into HotTips

Return to the Toast Inputs page and upload each file into the matching section.

Toast File HotTips Upload
Shifts CSV Shifts CSV
Orders CSV Orders CSV
Payments CSV Payments CSV
✓ A green checkmark appears when a file is accepted.
✓ Tables begin populating below the upload areas.
✓ Verify the correct CSV was selected if tables do not populate.

Completing Toast Inputs

  1. Confirm all three files have green checkmarks.
  2. Verify the dates are correct.
  3. Click Continue.

HotTips will move to the Manual Inputs page.

04

Manual Inputs

The Manual Inputs page contains three tabs:

Cash Drops Employee Config Summary
Important: Complete the tabs in this order. Cash Drops must be completed before Employee Config.

Cash Drops

Purpose

Enter the amount of cash collected for each employee and shift.

Breakfast
Lunch
Dinner

Entering Cash Drops

Enter the collected cash amount into the appropriate employee and shift. Press Enter to move downward and Tab to move right.

Cash Drop Warnings

Red: below expected amount
Grey: matches expected sales
Green: exceeds expected sales and indicates cash tips

Red cells are warnings only. HotTips will not prevent you from continuing.

05

Employee Config

After all cash drops have been entered, move to Employee Config. This section controls employee tip settings.

Employee Tip Points

The Tip Point system determines each employee's default tip weighting. A value of 1.0 means the employee receives 100% of their assigned point value. These values become the default points for the week.

Assigning Trainers

  1. Locate the employee.
  2. Open the trainer dropdown.
  3. Select the correct trainer.

Every trainee must have a trainer assigned before continuing.

Summary

Before continuing, review the Summary tab and confirm:

✓ Cash drops are correct.
✓ Employees are correct.
✓ Trainer assignments are complete.
✓ Tip points look correct.

After reviewing, click Continue to move to Tip Distribution.

06

Tip Distribution

The Tip Distribution page is where employee roles and meal block-specific settings are reviewed.

Day Each day of the process
Meal Breakfast, Lunch, Dinner
Role Employee distribution role

Editing Distribution Information

Meal Block Tip Points

Employee points can be adjusted for individual meal blocks. For example: Monday Breakfast 1 point, Monday Lunch 0.75 points, Monday Dinner 1 point. Changes only apply to that specific meal block.

Distribution Roles

Tip Owner
Server
Busser
Host
BOH
Other

Distribution Roles Explained

Server Receives from the server tip pool.
Busser Receives from the busser tip pool.
Host Receives from the host tip pool.
BOH Back of House employees, such as line cooks, prep cooks, and dishwashers.
Other Used for employees who should not receive tips. Employees assigned to Other receive $0 from tip pools.

Reviewing Tip Owners

At the top of each meal block are the Tip Owners. This section displays:

• Employee name
• Card tips
• Cash tips
• Pool distributions
• Total kept

Total Kept represents the employee's final amount after distributions.

Completing Tip Distribution

After all roles and points have been reviewed, click Continue to calculate the final results.

08

Saving and Loading Processes

HotTips allows completed processes to be saved for later review.

Saving a Process

Saving stores:

✓ Imported Toast data
✓ Cash drops
✓ Employee settings
✓ Trainer assignments
✓ Tip distributions
✓ Final calculations

To save a process, complete the process and click Save.

Loading Previous Processes

  1. Select Load History.
  2. Choose the saved process.

HotTips will restore the previous information so it can be reviewed or edited.

✓

PROCESS COMPLETE

You're ready for payroll.

Review the Payroll Summary, confirm that all information is correct, and the HotTips process is complete.
